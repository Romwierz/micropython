MicroPython port to Zynq SoC
============================

This is a port of MicroPython to the Zynq SoC.

Contributing to this port
=========================

Warning: some bsp files may require configuration macros that are typically placed in headers
generated by AMD/Xilinx development tools. Such files are: bspconfig.h, xparameters.h and xmem_config.h.
So in case of getting errors caused by undeclared macros, there is a great possibility that they should
be declared in one of these files. There are few options to fix such issue:
- properly configure the platform using the AMD/Xilinx tools (or some alternative) and generate the files;
- see examples of how these things are defined (e.g. in xilinx-embeddedsw/lib/{sw_apps,sw_services});
- use your intuition based on how these macros are already defined for other modules/peripherals.
